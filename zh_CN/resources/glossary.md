# 术语表

| 术语 | 含义 |
|---|---|
| ABI | 应用程序二进制接口：组件之间使用的数据布局和调用约定 |
| 生效的覆盖层 | 当前已应用到运行中内核的设备树覆盖层 |
| CLIC | 核心本地中断控制器，用于向 HP 核递送中断 |
| 设备树 | 描述硬件及其驱动使用的资源 |
| DTB | 编译后的设备树文件 |
| DTBO | 编译后的设备树覆盖层（overlay），加载后可添加或修改硬件描述 |
| FIT | U-Boot 镜像格式，包含启动组件及其元数据 |
| H4 | 蓝牙数据包封装格式，在每个 HCI 数据包前添加一个包类型字节 |
| HCI | 蓝牙主机协议栈与控制器之间的主机控制器接口 |
| HIL | 硬件在环测试，使用主机、开发板及可选的测试对端 |
| HP 核 / hart | 运行 Linux 的高性能 RISC-V 处理器之一 |
| LP 核 | 运行由 Linux remoteproc 管理的固件的低功耗处理器 |
| M-mode | RISC-V 机器模式，由 OpenSBI 使用 |
| S-mode | RISC-V 监管者模式，由 Linux 使用 |
| OpenSBI | 为 Linux 和 U-Boot 提供底层 RISC-V 服务的固件 |
| Payload | 在无线指南中，指由 Linux 驱动加载的外部无线固件 |
| Persist | 用于保存文件和设置的可写 JFFS2 flash 分区 |
| PSRAM | 外部伪静态 RAM，用作 Linux 的可写内存 |
| 资源声明 | 用于预留控制器、DMA 通道或其他共享资源的覆盖层条目 |
| 保存的覆盖层 | 为下次启动保存的预期覆盖层选择；`--volatile` 更改会保持此集合不变 |
| SPL | U-Boot 的小型第一阶段加载器，为后续启动阶段初始化开发板 |
| Sv32 | 用于 32 位地址空间的 RISC-V 虚拟内存地址转换机制 |
| XIP | 就地执行：直接从映射的 flash 中运行代码 |
