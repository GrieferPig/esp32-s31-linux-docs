# ESP32-S31 Linux 编程指南

欢迎使用 ESP32-S31 Linux 移植项目。本指南介绍如何在 ESP32-S31 上安装 Linux、连接外设和构建应用程序。

要在开发板上试用 Linux，请从[烧录与首次启动](get-started/flash-and-first-boot.md)开始。
要构建自己的镜像，请按照[从源码构建](get-started/build-from-source.md)操作。

Linux 启动后，可以按照 [Wi-Fi 与蓝牙设置](user-guides/networking.md)或[外设示例](user-guides/peripherals.md)操作。使用 `esp32-config` 配置开发板，并在[外设参考](api-reference/peripherals/index.md)中查阅接口和限制。
